Army AFT data reference

This reference is for people importing the five-event Army Fitness Test scoring tables into spreadsheets, scripts, or training applications. For interactive scoring, use AFTPTCalc.

Choose a download

  • Spreadsheet and JSON kit. Extract the ZIP and open thresholds.csv or data.json.
  • JavaScript package. Install aftptcalc-army-aft-data@0.1.1 from npm. This release contains the same scoring data.
  • Source, tests, and original-document archive.

Read one threshold with Python

After extracting the CSV kit, run this code in the same directory. It selects the published 60-point deadlift threshold for one age and scoring scale. It does not compute a pass decision.

import csv

age = 24
with open("thresholds.csv", newline="", encoding="utf-8") as file:
    rows = list(csv.DictReader(file))

matches = [
    row for row in rows
    if row["event"] == "mdl"
    and row["sex"] == "male"
    and row["points"] == "60"
    and int(row["age_min"]) <= age
    and (not row["age_max"] or age <= int(row["age_max"]))
]
if len(matches) != 1:
    raise ValueError(f"Expected one published threshold, got {len(matches)}")
row = matches[0]
print(row["comparison"], row["threshold"], row["unit"])

Keep the source meaning when importing

  • Keep event, sex, and both age bounds in the key. A blank upper bound represents the final published age band.
  • Check the unit and comparison before comparing raw performance. A timed threshold is stored as seconds. A lower value may be better.
  • In the source JSON, a null cell means no published threshold is listed for that combination. In the long CSV it is omitted. Do not substitute zero or interpolate across missing entries.
  • Record the sourceTitle, sourceUrl, effectiveDate, and verifiedOn from data.json when copying the dataset.

Provenance and scope

The tables were sourced from the Army's Army Fitness Test Scoring Scales (effective June 1, 2025). The dataset records verification on October 29, 2026. See the AFTPTCalc methodology for import and validation details. The dataset excludes alternate events, eligibility decisions, and administrative rules.
