Army AFT scoring data kit

Version 0.1.0 gives spreadsheet authors and developers the published thresholds for five regular Army Fitness Test events. The kit includes CSV, JSON, and a JavaScript lookup helper. For an interactive training estimate, use AFTPTCalc.

Find a threshold in a spreadsheet

  1. Open thresholds.csv and filter event to the event key. Use mdl for the maximum deadlift or run for the two-mile run.
  2. Filter sex to the published scale and select the inclusive age_min and age_max band. A blank upper limit marks the final age band.
  3. Filter points to the score you want to look up. Read the threshold alongside unit and comparison. A missing row means the source does not list that combination.

Read the same data in Node.js

Use Node.js 22.12 or later. In a project directory, install the versioned archive:

npm install https://github.com/jiankn/aftptcalc-army-aft-data/releases/download/v0.1.0/aftptcalc-army-aft-data-0.1.0.tgz

Save this example as lookup.mjs and run node lookup.mjs.

import { data, getThresholds } from 'aftptcalc-army-aft-data';

const scale = getThresholds({ event: 'mdl', age: 24, sex: 'male' });
const row = scale.rows.find(({ points }) => points === 60);
console.log(row?.threshold, scale.unit, scale.comparison);
console.log(data.sourceUrl);

Source and scope

The source is the Army’s Army Fitness Test Scoring Scales, effective June 1, 2025. The dataset records verification on October 29, 2026. See the AFTPTCalc methodology for the source archive and validation approach.

The kit supplies lookup thresholds for the regular five events. Combat-scale eligibility, alternate events, and overall pass decisions require the applicable official guidance.
